欢迎使用本本地播放器应用。

本应用为纯本地影音播放工具，全部解码、文件扫描均在您手机本地完成，无网络请求，不收集任何用户信息。

1. 数据收集
本应用不会收集、存储、上传、分享任何个人信息。
不会采集姓名、手机号、位置、设备标识等隐私数据。
不会上传您的视频、播放记录、浏览记录，所有内容仅保存在本机。

2. 权限说明

① 文件访问权限
本App读取系统「文件」App中本应用目录下的视频文件，用于本地播放。
仅读取本App沙盒目录内文件，不会访问其他App私有文件。
您复制到本App文件夹的视频，仅您本机可见，不会向外传输。

② 相册权限
本应用仅在您主动操作时申请相册权限：用于保存截图、保存视频画面到相册。
- 不会主动读取相册内图片、视频；
- 导出、截图文件仅保存在您本机相册；
- 系统设置中可随时关闭相册权限，关闭后截图导出功能失效，播放功能不受影响。

本App不会申请位置、通讯录、麦克风等无关权限。

3. 网络使用
本应用不访问互联网，不发起任何网络请求，无后台上传，无服务器。

4. 第三方服务
本应用不集成第三方SDK、统计、埋点、广告、追踪组件，不存在第三方获取您数据的渠道。

5. 用户数据
播放记录、扫描到的文件仅在App运行期间内存使用；
卸载应用，沙盒内全部文件会被系统清除。
您可以随时在系统「文件」App自行删除App目录内视频。

6. 免责声明
本应用仅做本地视频解码播放，不对视频内容负责。软件按现状提供，不做任何担保。

7. 隐私政策更新
后续版本如有功能变更，会更新本隐私声明。
